# ЛР1: Рекомендаційна система для елективних курсів — підготовка даних та кластеризація

Скорочена версія: 5 метрик схожості користувачів + 5 метрик схожості курсів, одна процедура кластеризації (агломеративна ієрархічна, k = 5…12 за максимальним силуетом), ТОП-10 «ядро» кожного кластера.

## Порядок запуску
```
pip install numpy pandas scipy scikit-learn matplotlib
python 01_generate_data.py     # синтетичні дані (seed 42) -> data/raw
python 02_preprocess.py        # очищення -> data/processed
python 03_cluster_users.py     # U1..U5 -> results/users_*, figures/users_*
python 04_cluster_courses.py   # C1..C5 -> results/courses_*, figures/courses_*
python 05_report_data.py       # зведений графік і report_data.json
cd report && NODE_PATH=$(npm root -g) node build_report.js   # (docx; потрібен пакет docx)
```

## Метрики
Користувачі: U1 Говер (анкета), U2 Евклід (анкета), U3 Жаккар (теги інтересів), U4 косинус (взаємодії), U5 Єнсен–Шеннон (профіль тем).
Курси: C1 TF-IDF косинус, C2 Говер (атрибути), C3 Жаккар (ключові слова), C4 косинус (взаємодії), C5 Жаккар (спільні користувачі).

Метрики на взаємодіях застосовуються лише до користувачів з ≥8 курсами та курсів з ≥10 користувачами; решту об'єктів віднесено до кластерів за резервною метрикою (kNN, k = 10).

## Файли
- `results/*_summary.csv` — якість (силует, ARI/NMI відносно прихованої розмітки, NMI відносно невикористаної ознаки).
- `results/*_cluster_labels.csv` — мітки кластерів (вхід для ЛР2: `cluster_C1`, `cluster_C3`, `cluster_C4`).
- `results/*_top10_*.csv`, `figures/*_top10_*.png` — ТОП-10 «ядра» кластерів.
